# AI Framework Labs

Welcome to **AI-Framework-Labs**, a repository for exploring the functionalities of AI frameworks: **LangChain**, **LangGraph**, **LlamaIndex**, **CrewAI**, **Hugging Face**, **Haystack**, and **AutoGen**. These labs use **Mistral** and open-source tools to build e-commerce applications like support bots and RAG systems.

---

## 🧠 Overview

### 🎯 Purpose

Dive into the core and advanced features of AI frameworks, including multi-agent systems for collaborative workflows.

---

## 🔧 Frameworks

- **LangChain**: Agentic workflows.
- **LangGraph**: Stateful agent orchestration.
- **LlamaIndex**: Data indexing and retrieval.
- **CrewAI**: Multi-agent collaboration.
- **Hugging Face**: NLP, datasets, and UI.
- **Haystack**: RAG and Q&A pipelines.
- **AutoGen**: Multi-agent systems for task automation and collaboration.

### 🛍️ Focus: E-commerce Use Cases

Examples include product queries, order status, refund handling, and automated customer support via multi-agent systems.

- Python 3.8+
