# AI Framework Labs

Welcome to **AI-Framework-Labs**, a repository for exploring the functionalities of AI frameworks: **LangChain**, **LangGraph**, **LlamaIndex**, **CrewAI**, **Hugging Face**, and **Haystack**. These labs use **Mistral** and open-source tools to build e-commerce applications like support bots and RAG systems.

---

## 🧠 Overview

### 🎯 Purpose

Dive into the core and advanced features of AI frameworks.

---

## 🔧 Frameworks

- **LangChain**: Agentic workflows.
- **LangGraph**: Stateful agent orchestration.
- **LlamaIndex**: Data indexing and retrieval.
- **CrewAI**: Multi-agent collaboration.
- **Hugging Face**: NLP, datasets, and UI.
- **Haystack**: RAG and Q&A pipelines.

### 🛍️ Focus: E-commerce Use Cases

Examples include product queries, order status, and refund handling.
